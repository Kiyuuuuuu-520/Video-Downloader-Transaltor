# Video-Downloader-Transaltor
Aprogram that can download videos from social media, encode then in to mp4 and generate an AI-powered, accurately translated SRT file for the videos.

The program is designed to automatically translate Youtube or any other websites and generate a h.264 coded  mp4 file for editing. It also translates the video into Mandarin and generate an SRT file through genmini.

All you need is sub in your google ai api to get everthing working!!!!!!!
